# สถาบันวิจัยและพัฒนาอัญมณีและเครื่องประดับแห่งชาติ

**ชื่อย่อ:** GIT (Gem and Jewelry Institute of Thailand)
**สังกัด:** กระทรวงพาณิชย์
**ประเภท:** องค์การมหาชน
**เว็บไซต์:** git.or.th

## ภารกิจหลัก
สถาบัน GIT มีภารกิจในการวิจัย พัฒนา และให้บริการด้านอัญมณีและเครื่องประดับ รวมถึงการตรวจสอบและรับรองคุณภาพอัญมณีและโลหะมีค่า เพื่อยกระดับและสร้างความน่าเชื่อถือให้แก่อุตสาหกรรมอัญมณีและเครื่องประดับไทยในตลาดโลก

## อำนาจหน้าที่
- ตรวจสอบและออกใบรับรองคุณภาพอัญมณี (เพชร พลอย ทับทิม มรกต ฯลฯ) และโลหะมีค่า
- วิจัยและพัฒนาเทคโนโลยีด้านอัญมณีและเครื่องประดับ
- ให้บริการฝึกอบรมและพัฒนาบุคลากรในอุตสาหกรรม
- เผยแพร่ข้อมูลและองค์ความรู้ด้านอัญมณีและเครื่องประดับ
- ส่งเสริมมาตรฐานและคุณภาพของอุตสาหกรรม

## กลุ่มเป้าหมาย / ผู้รับบริการ
- ผู้ประกอบการในอุตสาหกรรมอัญมณีและเครื่องประดับ
- ผู้ส่งออกและนำเข้าอัญมณีและเครื่องประดับ
- ผู้บริโภคที่ต้องการตรวจสอบคุณภาพอัญมณี

## กฎหมายหลักที่เกี่ยวข้อง
- พระราชกฤษฎีกาจัดตั้งสถาบันวิจัยและพัฒนาอัญมณีและเครื่องประดับแห่งชาติ พ.ศ. 2545
