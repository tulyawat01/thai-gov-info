# สำนักงานคณะกรรมการการรักษาความมั่นคงปลอดภัยไซเบอร์แห่งชาติ

**ชื่อย่อ:** สกมช. / NCSA (National Cyber Security Agency)
**สังกัด:** กระทรวงดิจิทัลเพื่อเศรษฐกิจและสังคม
**ประเภท:** หน่วยงานของรัฐ (ไม่ใช่ส่วนราชการ)
**เว็บไซต์:** ncsa.or.th

## ภารกิจหลัก
NCSA มีภารกิจในการกำกับดูแล ส่งเสริม และสนับสนุนการรักษาความมั่นคงปลอดภัยทางไซเบอร์ของประเทศ เพื่อป้องกันภัยคุกคามทางไซเบอร์ต่อโครงสร้างพื้นฐานสำคัญของชาติ

## อำนาจหน้าที่
- กำหนดนโยบายและแผนระดับชาติว่าด้วยการรักษาความมั่นคงปลอดภัยไซเบอร์
- กำกับดูแลหน่วยงานโครงสร้างพื้นฐานสำคัญทางสารสนเทศ (CIIP)
- ประสานงานรับมือภัยคุกคามไซเบอร์ระดับชาติ
- พัฒนามาตรฐานและแนวปฏิบัติด้านความมั่นคงไซเบอร์
- สนับสนุนการพัฒนากำลังคนด้านไซเบอร์

## กลุ่มเป้าหมาย / ผู้รับบริการ
หน่วยงานโครงสร้างพื้นฐานสำคัญ ภาครัฐและภาคเอกชน ผู้เชี่ยวชาญไซเบอร์ และประชาชนที่ได้รับผลกระทบจากภัยไซเบอร์

## กฎหมายหลักที่เกี่ยวข้อง
- พระราชบัญญัติการรักษาความมั่นคงปลอดภัยไซเบอร์ พ.ศ. 2562
