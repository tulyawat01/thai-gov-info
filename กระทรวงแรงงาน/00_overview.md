# กระทรวงแรงงาน

**ชื่อย่อ:** รง. / MOL
**เว็บไซต์:** mol.go.th
**สายด่วน:** 1506 (สำนักงานประกันสังคม), 1694 (กรมการจัดหางาน)

## ภารกิจหลัก
กระทรวงแรงงานมีภารกิจในการบริหารและคุ้มครองแรงงาน พัฒนาฝีมือแรงงาน ส่งเสริมการมีงานทำ รวมถึงดูแลระบบประกันสังคมและสวัสดิการของแรงงานทั้งในและนอกระบบ เพื่อให้แรงงานไทยมีคุณภาพชีวิตที่ดีตามมาตรฐานสากล

## อำนาจหน้าที่
- ส่งเสริมและพัฒนาฝีมือแรงงานให้ได้มาตรฐาน
- จัดหางานและส่งเสริมการมีงานทำแก่ประชาชน
- คุ้มครองแรงงานและดูแลสิทธิของลูกจ้าง
- บริหารระบบประกันสังคมและกองทุนทดแทน
- ส่งเสริมความปลอดภัยและอาชีวอนามัยในสถานประกอบการ
- บริหารแรงงานต่างด้าวและแรงงานไทยไปต่างประเทศ
