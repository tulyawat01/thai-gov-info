# กระทรวงการคลัง

**ชื่อย่อ:** กค. / MOF
**เว็บไซต์:** www.mof.go.th
**สายด่วน:** 1359

## ภารกิจหลัก
กระทรวงการคลังทำหน้าที่เกี่ยวกับการเงินของแผ่นดิน การภาษีอากร การรัษฎากร กิจการเกี่ยวกับที่ดินราชพัสดุ กิจการอันกฎหมายบัญญัติให้เป็นการผูกขาดของรัฐ และการบริหารหนี้สาธารณะ รวมถึงการกำกับดูแลและพัฒนารัฐวิสาหกิจ และการค้ำประกันหนี้ของส่วนราชการและองค์การรัฐ

## อำนาจหน้าที่
- การเงินของแผ่นดิน การภาษีอากร และการรัษฎากร
- กิจการเกี่ยวกับที่ดินราชพัสดุ (ที่ดินของรัฐ)
- กิจการอันกฎหมายบัญญัติให้เป็นการผูกขาดของรัฐ
- กิจการหารายได้ซึ่งรัฐมีอำนาจดำเนินการได้แต่เพียงผู้เดียวตามกฎหมาย
- การบริหารหนี้สาธารณะ
- กำกับดูแลและพัฒนารัฐวิสาหกิจ
- ค้ำประกันหนี้ของส่วนราชการ องค์การรัฐ สถาบันการเงิน และรัฐวิสาหกิจ
